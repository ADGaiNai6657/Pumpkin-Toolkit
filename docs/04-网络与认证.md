# 04 · 网络与认证

项目有两个网络客户端，都是 `object` 单例：

- `utils/QZClient.kt` —— 教务系统（正方/强智类），HTML 抓取 + Ktor + KSoup。
- `utils/SunshineClient.kt` —— 阳光服务平台，form POST + JSON。

## 1. QZClient（教务系统）

### 1.1 基础

- HTTP：Ktor `HttpClient { followRedirects = false }`，**手动处理 302 与 Cookie**。
- HTML 解析：KSoup（`com.fleeksoft.ksoup.Ksoup.parse`）。
- baseUrl：`url(path)` = `"${AppConfig.serverUrl.trimEnd('/')}/${path.trimStart('/')}"`（`QZClient.kt:75`）。
  - `AppConfig.serverUrl` 默认 `http://61.187.179.66:8924/`，可在设置切换为 `http://jwzx.usc.edu.cn:8924/`。
- 会话状态：`username` / `password` / `loginRedirectUrl` / `logged` / `cookies: MutableList<Cookie>`。

### 1.2 登录

- 直接赋值：`QZClient.username = ...; QZClient.password = ...`（登录页 / `App.kt:167` 自动登录）。
- `suspend fun login(...)`（`QZClient.kt:89`）流程：
  1. GET 验证码 `verifycode.servlet`
  2. 图像预处理 + 识别（`qzrc/QZRecognize.kt`）
  3. POST `Logon.do?method=logon`（表单 `userAccount/userPassword/RANDOMCODE`）
  4. 非 302 时解析 `#showMsg` 取错误信息
  5. 跟随 302 取 Cookie，成功则 `logged = true` 并触发登录成功回调
- 登录成功回调：`addLoginSuccessCallback((jwQuickUrl: String) -> Unit)`（`:56`）。
  - **全局唯一注册点**：`App.kt:119-165`，回调内拉取：全部课程、开学日期、总周数、学期列表、默认学期，写缓存并刷新小组件。
- `getHtml(url)`（`:173`）：带 Cookie 的 GET，检测到登录页会自动重登，最多重试。

## 2. SunshineClient（阳光服务平台）

- HTTP：Ktor，`followRedirects = false`，**不维护登录态**；纯 form POST + JSON。
- 基址固定为 `usc.tabbycms.com`，JSON 用 `JsonUtil`（kotlinx.serialization）。

## 3. 登录态与账号持久化

- 登录页（`MiuixLoginScreen.kt:63` / `Material3LoginScreen.kt:66`）：校验非空 → 赋值 `QZClient` → `login(onSuccess/onFailure)` → 成功写 `AppConfig.username/password` 并 `save()` → 返回。
- 启动自动登录：`App.kt:167-173`，若 KVault 里存有账号密码则赋值并 `QZClient.login()`。
- 账号密码存储于 KVault（`KEY.USERNAME` / `KEY.PASSWORD`）。
- 服务器地址：`KEY.SERVER_URL`，设置页可切换。

## 4. 异常与提示

- `login` 内部把异常统一转为中文提示（网络错误、验证码错误等）。
- 页面通常用 Snackbar 展示失败信息。
