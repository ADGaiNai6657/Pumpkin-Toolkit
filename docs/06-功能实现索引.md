# 06 · 功能实现索引

按功能列出"页面文件 / ViewModel / 数据来源 / 入口"，便于快速定位代码。
两套 UI 风格均在 `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/screens/` 下。

---

## 1. 首页与页签

| 项 | 位置 |
|---|---|
| 页面 | `screens/miuix/MiuixHomeScreen.kt:52`、`screens/material3/Material3HomeScreen.kt:55` |
| ViewModel | `viewmodel/HomeViewModel.kt:11`（`currentPagerIndex`） |
| 页签 | `["日程","课表","功能"]`，`HorizontalPager` 渲染 Today / Schedule / Function |
| 数据 | 无网络请求，仅承载子页面 |

## 2. 今日课程

| 项 | 位置 |
|---|---|
| 页面 | `screens/miuix/TodayScreen.kt:50`、`screens/material3/Material3TodayScreen.kt:46` |
| 数据 | `buildWeekCourses(viewModel.courseList)` → 取当前周 → 按今天 `dayOfWeek` 过滤 |
| 日期换算 | `(localDate.dayOfWeek.ordinal + 1) % 7`（把 ISO 周一=0 映射到课程 周日=0） |
| 入口 | 首页页签 0 |

## 3. 周课表

| 项 | 位置 |
|---|---|
