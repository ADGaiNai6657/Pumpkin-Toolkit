# 01 · 架构总览

## 1. 总体结构

项目是标准的 Kotlin Multiplatform（KMP）多模块工程：

```
PumpkinToolkit/
├── shared/        所有 UI 与业务逻辑（跨平台共享）
│   ├── commonMain/  通用代码（绝大部分）
│   ├── androidMain/ Android 平台实现（expect 的 actual）
│   └── iosMain/     iOS 平台实现
├── androidApp/    Android 应用壳（Activity、Manifest、Glance 小组件）
└── iosApp/        iOS 应用壳（SwiftUI 容器、WidgetKit 小组件）
```

- `shared/commonMain` 里用 Compose 写的界面，**Android 和 iOS 共用同一份**。
- 只有"每个平台做法不同"的能力才下沉到 `androidMain` / `iosMain`，通过 `expect` / `actual` 声明。
- `androidApp` / `iosApp` 只负责"启动 Compose"和平台特有资源（权限、小组件、签名）。

```
┌─────────────────────────────────────────────┐
│  androidApp: MainActivity → setContent{App()}│
│  iosApp: ContentView → MainViewController()  │
└───────────────────────┬─────────────────────┘
                        │  shared/commonMain
                        ▼
             ┌───────────────────────┐
             │        App.kt          │  根 Composable
             │  AppConfig.load()      │  全局配置
             │  CompositionLocal 注入  │  Navigator / AppViewModel
             └───────────┬───────────┘
                         │ 按 AppConfig.uiMode 分叉
           ┌─────────────┴─────────────┐
           ▼                           ▼
   MiuixTheme + NavDisplay     Material3AppTheme + NavDisplay
   （Miuix*Screen）             （Material3*Screen）
                         │
                         ▼
        pages ── 调用 ── QZClient / SunshineClient（object 单例）
                         │
                         ▼
        AppConfig（KVault 加密存储） / FileStoreUtils（JSON 文件缓存）
```

## 2. 分层职责

| 层 | 位置 | 职责 |
|---|---|---|
| 入口/壳 | `androidApp/`、`iosApp/` | 启动 Compose、平台资源、小组件 |
| 应用外壳 | `App.kt`、`Route.kt`、`Navigator.kt` | 主题切换、导航、全局注入、启动流程 |
| 页面 | `screens/miuix/`、`screens/material3/` | UI 与交互（两套风格） |
| 通用组件 | `components/` | 跨页面复用的 UI 组件 |
| 状态 | `viewmodel/` | 页面级/全局共享状态 |
| 业务/网络 | `utils/QZClient.kt`、`SunshineClient.kt` | 教务系统 / 阳光平台接口 |
| 数据模型 | `models/` | 数据结构定义 |
| 存储 | `utils/FileStoreUtils.kt`、`KVaultUtils.kt` | 文件缓存 / 加密键值 |
| 配置 | `AppConfig.kt` | 全局可变配置单例 |

## 3. 两种 UI 风格

项目同时维护 **Miuix**（小米风格）和 **Material 3** 两套界面，二者功能一一对应。

- 切换：`AppConfig.uiMode`（`0 = Miuix`，`2 = Material3`），入口在 `App.kt:186` 的 `when`。
- 页面命名：Miuix 版多为 `XxxScreen.kt`（部分带 `Miuix` 前缀），Material3 版统一 `Material3XxxScreen.kt`。
- 组件差异：

| 能力 | Miuix | Material 3 |
|---|---|---|
| 顶栏 | `SmallTopAppBar` | `TopAppBar` |
| 弹窗 | `WindowDialog` / `WindowBottomSheet` | `AlertDialog` / `ModalBottomSheet` |
| 列表项 | `BasicComponent` / `*Preference` | `M3Row`（自定义组件） |
| 加载 | `InfiniteProgressIndicator` | `CircularProgressIndicator` |
| 主题 | `MiuixTheme(controller=ThemeController)` | `MaterialTheme(...)`（`Material3Theme.kt`） |

> 新增功能时**两套都要改**，除非明确只支持一种风格。

## 4. 状态管理

- 全局状态：`AppViewModel`（`backStack`、`courseList`、`currentWeek`）、`AppConfig`（所有配置）。
- 页面状态：各 `viewmodel/XxxViewModel.kt`，继承 `androidx.lifecycle.ViewModel`，状态用 Compose 的 `mutableStateOf` / `mutableStateListOf` / `mutableStateMapOf` 持有。
- ViewModel 统一用 **Factory 模式**：`companion object { val Factory = viewModelFactory { initializer { XxxViewModel() } } }`，页面通过 `viewModel(factory = XxxViewModel.Factory)` 获取。
- 全局注入：`App.kt` 用 `CompositionLocalProvider` 下发 `LocalNavigator` / `LocalAppViewModel`。
- **本项目未使用 `viewModelScope` / `StateFlow`**：网络请求在页面的 `LaunchedEffect` 或 `rememberCoroutineScope().launch` 中直接调用 `QZClient` / `SunshineClient`，再回写状态。

## 5. 整体数据流

### 启动与课表加载
```
App() 启动
  └─ AppConfig.load()                     从 KVault 读配置
  └─ LaunchedEffect(startDate)            计算 currentWeek
  └─ coroutineScope.launch                读 schedule.json 缓存 → courseList
  └─ 若已存账号密码 → QZClient.login()
        └─ 登录成功回调 (App.kt:119)
              └─ QZClient.getAllCourses() / getStartDate() / getWeekNum() ...
              └─ 写 schedule.json、更新 AppConfig、刷新小组件
```

### 页面取数
```
页面 LaunchedEffect → QZClient.getXxx()/SunshineClient.getXxx()
   → 解析为 models
   → 写入 ViewModel 状态 或 本地缓存（FileName.*）
   → Compose 自动重组显示
```

## 6. 平台抽象（expect / actual）

| 能力 | `commonMain` 声明 | Android | iOS |
|---|---|---|---|
| 平台信息 | `expect fun getPlatform()` | `Platform.android.kt` | `Platform.ios.kt` |
| 文件目录 | `appDataDir()` / `appCacheDir()` | `FileStoreUtils.android.kt` | `FileStoreUtils.ios.kt` |
| 加密存储 | `createKVault()` | `KVaultUtils.android.kt` | `KVaultUtils.ios.kt` |
| 小组件数据 | `WidgetDataStore` / `reloadWidgetTimelines()` | `WidgetDataStore.android.kt` | `WidgetDataStore.ios.kt` |
| 高光/液态玻璃 | `rememberInteractiveHighlight()` / `isLiquidGlassSupported()` | 13+ RuntimeShader | 恒返回 null / true |
| 单调时钟 | `currentTimeMillis()` | `System.currentTimeMillis()` | `TimeSource.Monotonic` |
