## 这是什么项目

一个面向学生的校园工具箱应用（中南大学 / 南华大学教务系统等），提供：

- 课程表、今日课程
- 成绩查询、考试查询
- 空教室查询、课程执行计划
- 学生评教（含一键评教）
- 阳光服务平台（留言、失物招领）
- 教务系统 / 线上注册 / 成绩单 等 WebView 快捷入口
- 桌面小组件（今日 / 明日课程）

## 技术栈速览

| 类别 | 选型 |
|---|---|
| 语言 | Kotlin 2.4.10 |
| UI | Compose Multiplatform 1.11.1（Miuix 0.9.4-rc01 + Material 3） |
| 跨平台 | Kotlin Multiplatform（Android + iOS） |
| 网络 | Ktor 3.4.0 |
| HTML 解析 | KSoup 0.2.6 |
| 存储 | KVault 1.12.0（加密键值）+ Okio 3.17.0（文件） |
| 时间 | kotlinx-datetime 0.7.1 |
| 小组件 | Android Glance 1.1.1 / iOS WidgetKit |
| 构建 | Gradle 9.x + AGP 9.1.0 |
