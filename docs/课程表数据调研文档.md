# 课程表数据调研文档

## 1. 数据来源

### 1.1 网络客户端

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/QZClient.kt`

课程数据来自 **青果教务系统（QZClient）**，通过 HTTP 请求获取教务系统 HTML 页面，再使用 KSoup 解析。

- **Base URL**: 由 `AppConfig.serverUrl` 配置，默认 `http://61.187.179.66:8924/`
- **HTTP 客户端**: Ktor HttpClient（`followRedirects = false`）
- **会话管理**: 手动维护 Cookie 列表，支持自动重试登录（最多 3 次）

### 1.2 API 端点

| 方法 | URL 路径 | 用途 |
|------|----------|------|
| `GET` | `jsxsd/xskb/xskb_list.do?xnxq01id={termId}` | 获取**常规课程表** HTML |
| `GET` | `jsxsd/syjx/toXskb.do?xnxq01id={termId}` | 获取**实验课程表** HTML |
| `GET` | `jsxsd/jxzl/jxzl_query?xnxq01id={termId}` | 获取**学期信息**（开学日期、总周数） |
| `GET` | `jsxsd/kbcx/kbxx_classroom_ifr?...` | 获取**空教室查询**结果 |
| `GET` | `jsxsd/pyfa/pyfa_query` | 获取**课程执行计划** |
| `POST` | `Logon.do?method=logon` | 登录提交 |

### 1.3 登录流程

1. `GET verifycode.servlet` — 获取验证码图片 + Session Cookies
2. 验证码识别（`QZRecognize`）：二值化处理 + 4 字符模板匹配（34 个训练模板）
3. `POST Logon.do?method=logon` — 提交用户名、密码、验证码
4. 302 重定向 → 跟随 Location 获取最终 Cookies
5. 登录成功后触发回调，自动拉取课程数据

### 1.4 会话过期检测

响应 HTML 中包含 `<title>登录</title>` 时判定为会话过期，自动重新登录。

## 3. HTML 解析规则

### 3.1 常规课程表解析（`parseCourses`）

**数据来源**: `jsxsd/xskb/xskb_list.do`

```html
<!-- HTML 结构 -->
<table id="kbtable">
  <tbody>
    <tr>
      <td>
        <div class="kbcontent">
          课程名称<br>
          <font title="教师">张三</font><br>
          <font title="教室">101教室</font><br>
          <font title="周次(节次)">1-16(周1,2节)</font>
        </div>
      </td>
      <!-- 7列：周日到周六 -->
    </tr>
    <!-- 5行：对应10个节次 -->
  </tbody>
</table>
```

**解析逻辑**:
- `doc.select("#kbtable tbody")` → 主表格
- `table.select("tr")` → 行（1..5 为数据行，每行 2 个节次）
- `trs[i].select("td")` → 7 列（0=周日, 1=周一, ..., 6=周六）
- `td.selectFirst("div.kbcontent")` → 课程内容单元格
- 同一单元格多门课程用 `---------------------` 分隔

**字段提取**:
- `font[title=老师]` → 教师姓名
- `font[title=教室]` → 教室
- `font[title=周次(节次)]` → 周次信息，如 `"1-16(周1,2节)"`
- 剩余文本（移除 `<br>`, `<font>`, `<a>` 标签）→ 课程名称

**节次映射**:
- `dayOfWeek = j`（0=周日）
- `lessonOfDay = 2*i - 1`（第 1,3,5,7,9 节）

### 3.2 实验课程表解析（`parseExperimentCourses`）

**数据来源**: `jsxsd/syjx/toXskb.do`

```html
<table id="tblHead">
  <tbody>
    <tr>
      <!-- 实验课程数据 -->
    </tr>
  </tbody>
</table>
```

**解析逻辑**:
- `doc.select("table#tblHead tbody tr")` → 实验课程表
- 周次计算：`week = (i + 4) / 5`
- 每个 `<br>` 分隔的单元格：第 0 行 = 课程名，第 1 行 = 教室信息
- 教室提取：`texts[1].split(" ")[1]`
- 星期：`j - startJ`，节次：`(i%5)*2 - 1`

### 3.3 学期信息解析

**数据来源**: `jsxsd/jxzl/jxzl_query`

| 字段 | 解析方式 | 格式 |
|------|----------|------|
| 开学日期 | `trElements[1].select("td")[1].attr("title")` | `yyyy年MM月dd日` |
| 总周数 | `trElements.size - 2` | 整数 |

### 3.4 学期列表解析

**数据来源**: 页面中的 `#xnxq01id` 下拉框

```html
<select id="xnxq01id">
  <option value="2024-2025-1">2024-2025学年第一学期</option>
  <option value="2024-2025-2" selected>2024-2025学年第二学期</option>
</select>
```

- `doc.select("#xnxq01id option")` → 所有学期选项
- `option.attr("value")` → 学期 ID
- `option.text()` → 学期显示名称
- `option[selected]` → 当前学期

### 3.5 空教室解析

**数据来源**: `jsxsd/kbcx/kbxx_classroom_ifr`

```html
<table id="kbtable">
  <tbody>
    <tr>
      <td>101教室</td>
      <td>高等数学</td>  <!-- 非空 = 有课 -->
    </tr>
    <tr>
      <td>102教室</td>
      <td></td>          <!-- 空 = 无课 -->
    </tr>
  </tbody>
</table>
```

**解析逻辑**:
- `doc.select("#kbtable tbody tr")` → 表格行
- 每行第一个 `td` = 教室名称
- 后续 `td`：有非空文本 → 有课，全空 → 空闲
- 返回 `Map<String, Boolean>`（教室名 → 是否空闲）

### 3.6 课程执行计划解析

**数据来源**: `jsxsd/pyfa/pyfa_query`

```html
<table id="dataList">
  <tbody>
    <tr>
      <!-- 跳过表头 -->
      <td>学期</td>
      <td>课程编号</td>
      <td>课程名称</td>
      <td>开课单位</td>
      <td>学分</td>

```

**字段映射**:
| 索引 | 字段 |
|------|------|
| `tdElements[1]` | 学期 |
| `tdElements[2]` | 课程编号 |
| `tdElements[3]` | 课程名称 |
| `tdElements[4]` | 开课单位 |
| `tdElements[5]` | 学分 |
| `tdElements[6]` | 总学时 |
| `tdElements[7]` | 考核方式 |
| `tdElements[8]` | 课程性质 |
| `tdElements[9]` | 课程属性 |
| `tdElements[10]` | 是否考试 |

## 4. 数据存储

### 4.1 文件存储（FileStoreUtils）

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/FileStoreUtils.kt`

使用 **Okio FileSystem** 进行跨平台文件 I/O。

| 文件名 | 内容 | 路径 |
|--------|------|------|
| `schedule.json` | 课程表缓存（ScheduleCache） | `appDataDir/schedule.json` |
| `exam.json` | 考试信息缓存 | `appDataDir/exam.json` |
| `score.json` | 成绩缓存 | `appDataDir/score.json` |
| `widget_data.json` | 小部件数据 | `appDataDir/widget_data.json` |

**平台差异**:
- **Android**: `context.filesDir/schedule.json`
- **iOS**: `NSDocumentDirectory/schedule.json`

### 4.2 加密存储（KVaultUtils）

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/KVaultUtils.kt`

使用 **KVault** 库（Android: EncryptedSharedPreferences, iOS: Keychain）。

**课程表相关配置**:
| Key | 类型 | 说明 |
|-----|------|------|
| `start_date` | String | 开学日期（LocalDate 序列化） |
| `total_week` | Int | 学期总周数 |
| `default_term_id` | String | 当前学期 ID |
| `course_name_line` | Int | 课程名显示行数（默认 4） |
| `course_room_line` | Int | 教室显示行数（默认 2） |
| `course_teacher_line` | Int | 教师显示行数（默认 2） |
| `cell_height` | Int | 课程表单元格高度 dp（默认 70） |
| `time_season` | Int | 时间季节（0=自动, 1=夏秋, 2=冬春） |
| `lock_start_date` | Boolean | 是否锁定开学日期 |
| `term_filter_start` | Int | 学期筛选起始 |
| `tomorrow_schedule_enable` | Boolean | 是否启用晚间切换明日课程 |
| `tomorrow_switch_hour` | Int | 切换小时 |
| `tomorrow_switch_minute` | Int | 切换分钟 |

### 4.3 小部件数据存储（WidgetDataStore）

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/WidgetDataStore.kt`

使用 `expect/actual` 模式实现跨平台：

- **Android**: 保存 `widget_data.json` + 发送 `APPWIDGET_UPDATE` 广播
- **iOS**: 使用 App Groups 共享数据 + NSNotificationCenter 通知刷新

## 5. 数据流

### 5.1 应用启动加载

```
App.kt 启动
  → FileStoreUtils.readString("schedule.json")
  → JsonUtil.parseJson → ScheduleCache
  → 提取 cache.courses
  → 填充 viewModel.courseList
  → 构建 WidgetData → WidgetDataStore.save()
```

### 5.2 登录后拉取数据

```
QZClient 登录成功回调
  → getAllCourses(termId)
    → getCoursesHtml(termId) → parseCourses(html) → 常规课程
    → getExperimentCoursesHtml(termId) → parseExperimentCourses(html) → 实验课程
    → 合并为 List<Course>
  → viewModel.courseList.clear() + addAll(courses)
  → FileStoreUtils.writeString("schedule.json", ScheduleCache)
  → getStartDate() → AppConfig.startDate
  → getWeekNum() → AppConfig.totalWeek
  → getTermValueMap() → AppConfig.termData
  → WidgetDataStore.save() + reloadWidgetTimelines()
```

### 5.3 下拉刷新

在 `ScheduleScreen` 中触发，执行与 5.2 相同的流程。

### 5.4 其他学期课表

```
OtherScheduleViewModel
  → QZClient.getAllCourses(termId)  // 指定学期
  → QZClient.getStartDate(termId)
  → 内存缓存 courseListMap[termId]
```

## 6. 相关功能

### 6.1 今日课程 / 明日课程

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/TodayScheduleResolver.kt`

**逻辑**:
1. 检查是否启用"晚间切换"模式（`tomorrowScheduleEnable`）+ 当前时间 >= 切换时间
2. 目标日期 = 明日 或 今日
3. 使用 `WeekCalculator` 计算目标日期所在周数
4. 周数 <= 0 或 > totalWeek → 假期（空列表）
5. `buildWeekCourses()` 按周分组 → 按星期过滤

### 6.2 空教室查询

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/screens/miuix/MiuixEmptyRoomScreen.kt`

- 教学楼数据：`buildings.json`（打包在 `composeResources/files/`）
- 查询参数：学期 ID、楼宇 ID、星期、周次、节次
- 结果：`Map<String, Boolean>`（教室名 → 是否空闲），按拼音排序，空闲教室优先

### 6.3 课程执行计划

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/screens/miuix/MiuixPlanScreen.kt`

- 调用 `QZClient.getCoursePlan()`
- 支持按学期筛选
- 无持久化缓存，每次进入页面重新拉取

### 6.4 桌面小部件

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/WidgetDataHelper.kt`

- `buildWidgetData()` 将 `List<Course>` 转换为 `WidgetData`
- 教室名称前缀（"红湘校区"、"雨母校区"）会被移除
- `getRemainingCourses()` 获取今日未结束的课程
- `getTomorrowCourses()` 获取明日完整课表

### 6.5 时间节次定义

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/constants/TimeList.kt`

| 节次 | 夏秋时间 | 冬春时间 |
|------|----------|----------|
| 1 | 08:00-08:45 | 08:20-09:05 |
| 2 | 08:55-09:40 | 09:15-10:00 |
| 3 | 10:00-10:45 | 10:20-11:05 |
| 4 | 10:55-11:40 | 11:15-12:00 |
| 5 | 15:00-15:45 | 14:30-15:15 |
| 6 | 15:55-16:40 | 15:25-16:10 |
| 7 | 17:00-17:45 | 16:30-17:15 |
| 8 | 17:55-18:40 | 17:25-18:10 |
| 9 | 20:00-20:45 | 19:30-20:15 |
| 10 | 20:55-21:40 | 20:25-21:10 |

**选择逻辑**: `timeSeason` = 0（自动：5-9月=夏秋，其他=冬春）、1（夏秋）、2（冬春）

### 6.6 周次计算

**文件**: `shared/src/commonMain/kotlin/com/pgigi/pumpkintoolkit/utils/WeekCalculator.kt`

- `getWeekNumber(date)` → 计算日期所在周数（相对开学日期）
- `getWeekFirstDay(weekNum)` → 获取指定周的周日（一周第一天）
- `buildWeekCourses()`（Extensions.kt）→ 遍历所有课程，展开周次范围，按周分组
