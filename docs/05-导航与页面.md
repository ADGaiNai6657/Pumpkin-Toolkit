## 2. 导航器：`Navigator.kt`

`Navigator` 包装后台栈 `NavBackStack`，提供：

| 方法 | 作用 |
|---|---|
| `push(key)` | 入栈跳转 |
| `replace(key)` | 替换栈顶 |
| `pop()` | 出栈（栈内 >1 才会出） |
| `popUntil(predicate)` | 回退到满足条件的页 |
| `navigateForResult(route, requestKey)` | 跳转并等待结果 |
| `setResult(requestKey, value)` | 设置结果并 `pop()` |
| `observeResult(requestKey)` | 以 `SharedFlow` 订阅结果 |
| `clearResult(requestKey)` | 清除结果 |

- 结果通道用 `MutableSharedFlow(replay = 1)`。
- 典型用例：评教详情页提交成功后 `setResult("evaluation_refresh", true)`，列表页 `observeResult` 收到后刷新。

## 3. `App.kt` 中的路由分发

- `navigator = remember(viewModel.backStack) { Navigator(viewModel.backStack) }`（`App.kt:83`）。
- 通过 `CompositionLocalProvider` 下发 `LocalNavigator` / `LocalAppViewModel`（`App.kt:175`）。
- 按 `AppConfig.uiMode` 分叉：
  - `2` → `Material3AppTheme { NavDisplay { entry<Route.X> { Material3XScreen() } } }`（`App.kt:187-260`）
  - `else` → `MiuixTheme { NavDisplay { entry<Route.X> { XScreen() } } }`（`App.kt:261-341`）
- 两套分支的 `entry` 一一对应（M3 版约 `App.kt:195-257`，Miuix 版约 `App.kt:276-338`）。
- `backStack` 初始为 `listOf(Route.Home)`（`AppViewModel.kt:16`）。

## 4. 首页内部的三个页签（不是 Route！）

`ScheduleScreen`、`TodayScreen`、`FunctionScreen` **不通过路由跳转**，而是 `HomeScreen` 里的一个 `HorizontalPager`：

- 页签定义：`MiuixHomeScreen.kt:46` / `Material3HomeScreen.kt:48`，`items = ["日程","课表","功能"]`。
- Pager 内容：`MiuixHomeScreen.kt:124-128` / `Material3HomeScreen.kt:133-137`
  - `0 -> TodayScreen()`
  - `1 -> ScheduleScreen()`
  - `2 -> FunctionScreen()`
- 当前页记在 `HomeViewModel.currentPagerIndex`。
- 底部导航栏 / 横屏 `NavigationRail` / 悬浮导航栏由 `AppConfig.floatingNavigation` 控制。

```
Route.Home
  └─ HomeScreen
       ├─ [0] TodayScreen     今日课程
       ├─ [1] ScheduleScreen  周课表
       └─ [2] FunctionScreen  功能入口（从这里 push 其它 Route）
```
