# 08 · 构建与运行

## 1. 环境要求

| 项 | 要求 |
|---|---|
| JDK | 21（`androidApp` 与 `shared` 均用 `JvmTarget.JVM_21`） |
| Gradle | 使用项目自带 wrapper（`gradlew` / `gradlew.bat`），无需单独安装 |
| Android 开发 | Android Studio（含 Android SDK） |
| iOS 开发 | macOS + Xcode（Windows 无法构建 iOS） |
| Android SDK | `compileSdk = 37`、`minSdk = 24`、`targetSdk = 36` |

## 2. 版本号在哪里改

- 全局依赖版本：`gradle/libs.versions.toml`
- 应用版本：`libs.versions.toml` 的 `appVersionCode` / `appVersionName`（被 `androidApp/build.gradle.kts:51-52` 使用）
- iOS 版本：由 Xcode 工程的 `Info.plist` / build settings 决定

主要版本（截至当前）：

| 组件 | 版本 |
|---|---|
| Kotlin | 2.4.10 |
| Compose Multiplatform | 1.11.1 |
| Material3 | 1.11.0-alpha07 |
| AGP | 9.1.0 |
| Miuix | 0.9.4-rc01 |
| Ktor | 3.4.0 |

## 3. 模块与构建产物

- `:shared` —— KMP 库。Android 产出 AAR；iOS 产出名为 **`Shared`** 的静态 framework（`isStatic = true`）。
  - iOS targets：`iosArm64`（真机）、`iosSimulatorArm64`（Apple Silicon 模拟器）。
- `:androidApp` —— Android 应用，依赖 `:shared`。
- iOS 主工程通过 Xcode 的 Run Script 调用 Gradle 生成并嵌入 framework。

## 4. Android 构建

推荐用 Android Studio 打开根目录直接运行。

命令行（Windows PowerShell）：

```powershell
# Debug 包
.\gradlew.bat :androidApp:assembleDebug

# Release 包
.\gradlew.bat :androidApp:assembleRelease
```

- `applicationId = com.pgigi.pumpkintoolkit`。
- Release 未开启混淆（`isMinifyEnabled = false`）。

### 签名（可选）

`androidApp/build.gradle.kts:11-21` 会读取根目录 `\.env`（若存在），字段：

```
KEYSTORE_PASSWORD=...
KEY_ALIAS=...
KEY_PASSWORD=...
KEY_STORE_PATH=...
```

- 若 `.env` 不存在或 `KEY_STORE_PATH` 为空，则沿用 Gradle 默认 debug keystore。
- **`.env` 含密钥信息，不要提交到仓库。**

## 5. iOS 构建

1. 用 Xcode 打开 `iosApp/iosApp.xcodeproj`。
2. 选择 target `iosApp`，运行。
3. Xcode 会在构建阶段执行脚本（见 `iosApp/iosApp.xcodeproj/project.pbxproj`）：
   ```
   ./gradlew :shared:embedAndSignAppleFrameworkForXcode
   ```
   该命令在仓库根目录运行，生成并嵌入 `Shared` framework。
4. Widget 扩展 target 与主应用共享 App Group：`group.com.pgigi.pumpkintoolkit`（见 `shared/src/iosMain/.../utils/WidgetDataStore.ios.kt:10`、两个 `.entitlements`）。

### iOS 小组件刷新链路

```
Kotlin 侧 WidgetDataStore.save()  → App Group 写文件 + NSUserDefaults
Kotlin 侧 reloadWidgetTimelines() → NSNotificationCenter 发通知
Swift 侧 WidgetReloader / ContentView 收到通知 → WidgetCenter.reloadTimelines
```

## 6. 测试

- `shared` 已声明 `commonTest` 依赖 `kotlin-test`（`shared/build.gradle.kts:102-104`），但当前仓库尚无测试源码目录。
- 如需添加：在 `shared/src/commonTest/kotlin/...` 下编写，运行 `.\gradlew.bat :shared:allTests`（或对应 target 的 test 任务）。

## 7. 常用 Gradle 任务速查

| 任务 | 说明 |
|---|---|
| `:androidApp:assembleDebug` | 打 Android Debug 包 |
| `:shared:embedAndSignAppleFrameworkForXcode` | 生成 iOS framework（由 Xcode 调用） |
| `:shared:compileKotlinIosArm64` | 仅编译 iOS 真机 Kotlin |
| `:shared:allTests` | 运行 shared 全部测试 |
| `tasks` | 查看全部任务 |

## 8. 构建配置说明

- `gradle.properties`：开启 configuration cache 与 build cache，JVM 内存 4G。
- `settings.gradle.kts`：仓库限定（google 只取 androidx/com.android/com.google + mavenCentral），只包含 `:androidApp` 与 `:shared`。
- 根 `build.gradle.kts`：只声明插件并 `apply false`，具体配置在各子模块。

## 9. 注意事项

- **修改 `shared/commonMain` 会同时影响 Android 与 iOS**，因为两端共用同一份 Compose 代码。
- iOS 相关能力（小组件、Keychain、App Group）依赖 Xcode 工程配置与 entitlements，改签名/团队时需同步调整。
- 项目使用 `.env` 管理 Android 签名，使用 Xcode 管理 iOS 签名，二者相互独立。
