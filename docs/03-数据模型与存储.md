## 3. 本地存储

### 3.1 加密键值存储 · KVault（`KVaultUtils.kt`）

- `commonMain` 用 `expect fun createKVault()`；Android = EncryptedSharedPreferences，iOS = Keychain。
- 提供 String/Int/Long/Float/Double/Boolean/ByteArray 的 `put/get`，以及 `contains/remove/clear/keys`。
- **用途**：保存所有用户配置（账号密码、服务器地址、开学日期、主题、课表设置等）。
- 配套：`AppConfig.kt` 统一读写。

### 3.2 文件缓存 · Okio（`FileStoreUtils.kt`）

- `expect fun appDataDir()` / `appCacheDir()`；Android = `filesDir`/`cacheDir`，iOS = Documents/Caches。
- 提供 `writeString/readString`、`writeBytes/readBytes`、`exists/delete`。
- **用途**：课表、成绩、考试的 JSON 缓存文件；小组件数据文件。

### 3.3 资源读取 · Compose Resources（`ResourceUtils.kt`）

- `readText` / `readBytes` / `exists`，从 `composeResources/files/` 读取。
- **用途**：`buildings.json`（教学楼）、`open-source-license.json`、拼音词库等。

### 3.4 JSON · `JsonUtil.kt`

- 封装 kotlinx.serialization：`toJson` / `parseJson` / `toListJson` / `parseListJson`。
- 配置：`ignoreUnknownKeys=true`、`isLenient=true`、`encodeDefaults=true`。

## 4. 缓存读写责任表

| 缓存 | 文件 | 写入点 | 读取点 |
|---|---|---|---|
| 课表 `ScheduleCache` | `schedule.json` | 登录成功回调 `App.kt:125`、两个 `ScheduleScreen` 下拉/刷新 | 启动 `App.kt:101` → `AppViewModel.courseList` |
| 成绩 `ScoreCache` | `score.json` | `viewmodel/ScoreViewModel.kt:37` | `ScoreViewModel.loadScoreCache():23` |
| 考试 `ExamCache` | `exam.json` | `viewmodel/ExamViewModel.kt:52` | `ExamViewModel.loadExamCache():38` |

> 非缓存型数据（其他学期课表、空教室、执行计划、评教）只存在内存 ViewModel 中，不落盘。

## 5. 小组件数据流

```
WidgetDataHelper.buildWidgetData(courses, startDate, totalWeek, timeSeason)
        │  生成 WidgetData（含时间表、课程、开学日期）
        ▼
WidgetDataStore.save(data)                     expect/actual
   ├─ Android: filesDir/widget_data.json
   └─ iOS: App Group 的 NSUserDefaults + 容器内 widget_data.json
        ▼
reloadWidgetTimelines()                         expect/actual
   ├─ Android: 发 APPWIDGET_UPDATE 广播（另有 30 分钟系统刷新）
   └─ iOS: 发 NSNotification → Swift WidgetReloader → WidgetCenter.reloadTimelines

读取（小组件侧）
   ├─ Android: TodayScheduleWidget.readWidgetData() 读 filesDir/widget_data.json
   └─ iOS: WidgetHelper.loadWidgetData() 读 App Group
```

- 触发刷新位置：`App.kt:98/114/163`、`AppConfig.kt:148`、两个 `ScheduleScreen` 刷新回调。
- 计算逻辑（今日剩余/明日课程、假期判断）在 `WidgetDataHelper.kt`：`getRemainingCourses():92`、`getTomorrowCourses():115`、`isHoliday():71`。
