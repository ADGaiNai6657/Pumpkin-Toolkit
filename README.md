## 已实现功能
- 课程表查看
- 成绩查询
- 考试查询
- 空教室查询
- 课程执行计划查询
- 其他学期课表查询
- 教务系统、线上注册及成绩单 快捷入口
- 学生评教
- 阳光服务平台接入

## 特色功能
- 两种 UI 风格 (Miuix、Material 3)
- 浅色、深色、自动切换模式自选
- 成绩查询时，隐藏不及格成绩 (手动设置)
- 一键自动完成学生评教 (手动发起操作)
